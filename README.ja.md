# Lime Columns

[English](README.md) | **日本語**

WordPress 管理画面の一覧テーブルの列を管理する、独立したプラグインです。列の追加・削除・並び替え・幅の調整、並び替え・検索・エクスポートの可否、カスタムフィールド（ACF を含む）の表示を、1 つの設定画面からまとめて行えます。

Lime Columns はゼロから書かれており、他のカラム管理プラグインのコードやアセットは一切流用していません。日本産プラグインです。

> **状態:** 開発初期（v0.1.0）。API や保存形式は変更される可能性があります。

## 機能

- **列の管理 UI** — ドラッグ＆ドロップ（または矢印ボタン）で並び替え。列ごとにラベルと幅（`%` / `px`）を設定できます。
- **投稿・ユーザーの一覧テーブル** — 投稿タイプごとの一覧と、ユーザー一覧に対応しています。
- **28 種類の列タイプ** — WordPress 標準の列（タイトル・投稿者・日付・コメントなど）、投稿フィールド、タクソノミー、サムネイル、最新コメント、カスタムフィールド、ユーザーフィールドなど。
- **並び替え** — 並び替え可能な列で並び替えできます。メタ値でも動作し、空の値は常に末尾になり、行が欠落することはありません。
- **検索** — WordPress 標準の検索窓にそのまま対応します。専用の検索フォームを覚える必要はありません。選んだ列を標準の検索の対象に含められます。カスタムフィールド／ACF の値、投稿者名（表示名・ログイン名）、タクソノミーのターム名に対応しています。投稿の一覧テーブルで利用できます。
- **既定の並び順** — 一覧ごとに初期の並び順を設定できます。
- **CSV エクスポート** — 一覧に表示される内容を、同じクエリ・条件でそのままエクスポートします。
- **ロールによる制限** — 設定を特定のロールにだけ適用できます。
- **ACF 連携** — 画面に適用される ACF フィールドグループの全フィールドを、列タイプの一覧に 1 件ずつ表示します。フィールド型に応じた整形（日付・セレクト・ファイル・リレーション・繰り返しなど）も行います。
- **Admin Columns からのインポート** — Admin Columns（Pro）が保存した一覧テーブルの設定を、Lime Columns の設定に変換します。ドライラン（プレビュー）に対応し、元のテーブルは読み取るだけで変更しません。

## 動作要件

- WordPress 6.5 以上
- PHP 8.1 以上
- Advanced Custom Fields（任意。ACF 連携を使う場合）

## インストール

1. このリポジトリをダウンロードまたはクローンして、`wp-content/plugins/lime-columns` に置きます。
2. プラグイン画面で **Lime Columns** を有効化します。
3. **設定 → Lime Columns** を開きます。

ビルド手順は不要です。設定画面は素の ES モジュールで動作します。

## 使い方

1. 左のサイドバーで一覧画面を選びます（設定済みの画面には点が付きます）。
2. **Choose a column type…** から列タイプを選び、**Add column** をクリックします。ACF のフィールドは **ACF** グループに並びます。
3. 列を展開して、ラベル・幅・並び替え／検索／エクスポートの可否を編集します。
4. ドラッグで列の順序を入れ替え、**Save** をクリックします。

Admin Columns から移行するには、**Import from Admin Columns** を開き、**Preview** で変換できる列を確認してから **Import** を実行します。Lime Columns の設定がすでにある画面を置き換えるには、**Overwrite** をオンにします。

> Admin Columns（Pro）が有効な間、Lime Columns は一覧画面には適用されません。切り替えるときは Admin Columns を無効化してください。それまでも、設定画面とインポート機能は使えます。

## ロードマップ

インライン編集、一括編集、絞り込み、保存済みビュー、条件付き書式、メディア・コメント・タクソノミーの一覧への対応。

## 免責事項

Lime Columns は、Admin Columns の開発元とは提携・承認・後援の関係にありません。「Admin Columns」の名称は、インポート機能が読み取る設定の取得元を示すためだけに使用しています。
